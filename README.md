# Keyboard Controls – LifeGame (Implementation Accurate)

## 実行制御

| キー      | 動作                   |
| ------- | -------------------- |
| `Space` | 実行 / 停止 切替 |

---

## 盤面操作

| キー      | 動作            |
| ------- | ------------- |
| `C`     | 全セル消去         |
| `R`     | ランダム配置        |
| `Enter` | カーソル位置のセルをトグル |

---

## ファイル操作

| キー         | 動作                         |
| ---------- | -------------------------- |
| `Ctrl + S` | JSON保存                     |
| `Ctrl + O` | ファイルを開く                    |
| `O`        | LGSモード開始（structureが存在する場合） |

---

## LGSモード制御

| キー    | 動作       |
| ----- | -------- |
| `X`   | LGSモード終了 |
| `Esc` | LGSモード終了 |

※ LGSMode が true のときのみ有効

---

## FPS制御

| キー          | 動作    |
| ----------- | ----- |
| `Ctrl + ↑`  | FPS増加 |
| `Ctrl + ↓`  | FPS減少 |
| `Shift + ↑` | FPS増加 |
| `Shift + ↓` | FPS減少 |

修飾キーが押されている場合のみ
`scrollFPS()` が呼ばれます。

---

## カーソル移動（キーボード）

修飾キーなしで矢印キーを押すとカーソルが移動します。

| キー  | 動作   |
| --- | ---- |
| `↑` | 上へ移動 |
| `↓` | 下へ移動 |
| `←` | 左へ移動 |
| `→` | 右へ移動 |


## デバッグ用

| キー  | 動作           |
| --- | ------------ |
| `T` | ウィンドウタイトル再描画 |
